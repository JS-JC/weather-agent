# 天气查询 AI Agent

一个基于 DeepSeek API 的天气查询智能体（Agent）。它能够识别用户的自然语言提问，自动判断该调用哪个工具，并调用工具完成天气查询后，再让大模型总结并返回最终答案。

## 功能特性

- 支持多城市天气批量查询：一条消息即可同时查询多个城市的天气
- 消息发送功能示例：演示大模型如何按需调用非查询类工具
- 采用「大模型输出工具指令 JSON → 本地解析并执行工具 → 结果回填让大模型总结」的 Agent 调用范式
- 内置城市支持：城市名到气象编码的本地映射，支持北京、上海、广州、深圳、石家庄、张家口、秦皇岛、衡水、保定、邯郸等河北及一线城市

## 使用前提：配置 DeepSeek API Key

> **必需**：程序运行时从环境变量读取 DeepSeek 的 API Key。**未配置会直接报错退出**，请务必先完成这一步。

```bash
# Windows (PowerShell)
$env:DEEPSEEK_API_KEY="你的key"

# macOS / Linux
export DEEPSEEK_API_KEY="你的key"
```

> 也支持使用项目下的 `.env` 文件（已被 `.gitignore` 忽略，不会被上传泄漏），将 API Key 放入其中，程序会自动忽略该文件。

## 环境要求

- Python 3.x
- 安装依赖：`pip install requests`

## 使用说明

1. 按上方步骤设置环境变量 `DEEPSEEK_API_KEY`
2. 运行脚本：

   ```bash
   python agent_full.py
   ```

3. 输入你想查询的城市名（可多个），例如：`秦皇岛今天天气怎么样？`；输入 `退出` 或 `q` 结束程序。

> 如果需要让程序读取 `.env` 文件，可自行安装并调用 `python-dotenv`，在脚本开头加载即可；当前版本直接读取系统环境变量。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `agent_full.py` | 主程序，AI 天气查询 Agent |
| `测试抓取返回数据.py` | 抓取某城市天气接口返回结构，用于调试 |
| `中国城市天气编码.txt` | 中国各城市对应的气象编码对照表 |

## 工作原理

1. 系统提示词告诉大模型：天气问题只输出 JSON 工具指令
2. 大模型返回如 `{"tool": "get_weather", "city": "秦皇岛"}`
3. 本地代码解析 JSON，调用对应工具（`get_weather` / `send_message`）
4. 工具返回结果回填到上下文，让大模型生成给用户看的最终回答

> 天气数据来自 t.weather.itboy.net 提供的公开接口，仅用于学习演示。
